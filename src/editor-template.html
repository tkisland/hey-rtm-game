MVに合わせてノーツを自動再生します。長オシは帯とHOLD、同時オシは連結線で確認できます。

ノーツを追加すると再生できます。

ノーツ音は譜面の時刻で鳴ります。再生が始まらない場合はMV内の再生ボタンを押してください。

ノーツの中心が判定の基準です。薄い帯がGOOD、中間がGREAT、濃い帯がPERFECT。自動再生は入力補正0msで表示します。

入力・タップ音のタイミング調整

一定間隔の音に合わせてタップし、入力補正の目安を測定します。ゲームと共通です。

＋は打ち込みを早い時刻へ、−は遅い時刻へ補正します。長オシの始点・終点も同じ量だけ補正します。判定時刻の補正はゲームと共通です。補正済みの時刻を譜面に保存し、設定を変えても保存済みノーツは動かしません。

入力から音を鳴らすまでの追加待ち時間。0msが最短です。入力より前には鳴らせず、端末・Bluetoothの遅れを短縮する機能ではありません。設定はゲームと共通です。

停止中。打ち込み開始を押してからMVを再生します。

S / D / F / J / K / L または6ボタンで入力。動画操作後は下の入力エリアをクリックしてください。一時停止・読込中は記録しません。追加の打ち込みは既存のノーツに重ねます。長オシは離すと保存します。再生停止・シーク・入力キャンセルで未完了の長オシは破棄します。

タイムライン

「範囲を選択」に切り替えて横にドラッグ、または下の範囲編集で秒数を指定します。

範囲のコピー・貼り付け・削除

コピーはこのページ内で保持します。全6レーンで、始点が開始以上・終了未満のノーツが対象です。長オシは終点まで、休符・同時オシもそのままコピーします。

色付きノーツをドラッグして移動。薄い輪郭は元の入力位置、縦線は拍です。上の秒数目盛りを押すとMVをシークします。長オシは帯の右端をドラッグすると終点を変更できます。連結線は同時オシ。細かい調整は下の数値欄でもできます。

PCではShift＋ドラッグでも範囲選択できます。タイムラインにフォーカスした状態でCtrl / ⌘＋Cでコピー、Ctrl / ⌘＋Vで指定位置へ貼り付け、Deleteで範囲削除、Escで選択解除。コピー・貼り付けのボタンはスマホでも使えます。

タイムラインか一覧でノーツを選択してください。

MIDIを読み込む・ギミックの指定方法

1チャンネルで指定できます。番号はMIDIノート番号です。左からピンク・黄緑・白・赤・紫・黄色。通常音符は1.5拍以上で長オシ、同時刻で同時オシです。

DD60（1音で全色対応）長さは無視・どれか1ボタンで1回得点
オシ変62, 64, 65, 67, 69, 71別の色へ（離れた色も可）、前の終端と次の始端をつなぐ。最後の終端で離す

箱オシは中央の白・赤から2本指で左右へ開く操作です。2本目は最初の指から0.15秒以内、左右の完走は0.35秒以内。PCは F＋J → D＋K → S＋L。開始は前後0.35秒まで受け付け、完走で1ノーツ分を採点します。オシ変は縦の帯で保持し、横向きの矢印が判定線に来たら矢印の先の色へ持ち替えます。途中のレーンは通過扱いです。途中と二重線の終端のすべてがGOOD以上で得点。音符の重なり・指定不足はエラーとして表示します。オシ変は各区間30ms以上、別のオシ変との間には休符を入れてください。既存の編集内容は「元に戻す」で復元できます。

編集内容はこのブラウザに自動保存します。他の端末に移す・バックアップする場合はJSONを書き出してください。試遊用の譜面は「ゲームで試す」で更新されます。読み込みと空の譜面への変更も「元に戻す」で戻せます。
