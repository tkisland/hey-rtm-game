# MIDIで推しノーツを作る

管理者画面の「保存と試遊 → MIDIを読み込む・ギミックの指定方法」から `.mid` / `.midi` を読み込めます。「動画上のMIDI開始位置」に、MIDIの0tickを動画の何秒に合わせるかを指定します。SUPER MOMMY GIRLSは **7.65秒**。読み込み後は「再生確認」か「ゲームで試す」で確認し、下書き保存・公開へ進めます。読み込み失敗では現在の編集を保持し、成功後も「元に戻す」で復元できます。

1つのMIDIチャンネルに、以下の番号の音符を配置してください。トラックを分けることもできますが、全トラックを時刻順にまとめて判定します。DAWのC3/C4などの名前はソフトによって異なるため、**MIDIノート番号**で確認してください。ベロシティに特別な指定はありません（0は通常のノートオフ扱い）。

| ノーツ | ピンク | 黄緑 | 白 | 赤 | 紫 | 黄色 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 単推し／長推し／同時推し | 38（39も可） | 40 | 41 | 43 | 45 | 47 |
| 箱推し | 50 | 52 | 53 | 55 | 57 | 59 |
| 推し変 | 62 | 64 | 65 | 67 | 69 | 71 |

**DDは60番の1音**です。表示は中央の虹色カプセルで、好きなレーンを1つ押せば得点します。複数押しても、そのDDノーツの得点は1回だけです。

## 既存のノーツ

- 単推し：通常音域の1.5拍未満の音符。1.5拍以上は長推しです。拍は四分音符で、テンポ変更があってもtickの長さで判定します。
- 同時推し：異なるレーンに同時刻（1ms以内）で配置。全員がGOOD以上で得点、1本でもMISSなら組全体が0点です。
- 長推し：先頭で押し、最後の終端で離します。始点と終端の悪い方が最終判定です。終端がMISSなら0点です。

## 箱推し：6色のチェーン

専用音域の **50・52・53・55・57・59** を1回ずつ、**違う時刻**に置きます。順番は自由です。専用音域のノーツを時刻順で6個ずつ1チェーンにするので、2チェーンなら12個、3チェーンなら18個にします。音符の長さは無視して、すべて単推しとして扱います。

例：50 → 52 → 53 → 55 → 57 → 59を1拍間隔に置くと、ピンクから黄色へ進む箱推しです。画面では番号と線でつながり、6個すべてGOOD以上で「箱推し成功！」と表示します。各ノーツは通常どおり採点します。追加ボーナスはありません。6本同時に押す操作は要求しません。

管理者エディターでは、通常の単推し6個（6色1個ずつ）を範囲選択して「6色を箱推しにする」でも作れます。チェーンの一部を削除・別の種類へ変更すると、残りは通常の単推しに戻ります。チェーンの一部だけコピーした場合も通常の単推しになり、6個丸ごとコピーすれば別チェーンとして貼り付けます。

## DD：好きな色で押す

**60番**を押したい時刻に配置します。音符の長さは無視します。長い60番もDD1個です。同時推しの連結には含めません。通常ノーツと同時刻なら通常の色の判定を優先し、DDには別の入力が必要です。初心者向け譜面では、ほかのノーツと十分離すと遊びやすくなります。

エディターでは選択ノーツの「種類」をDDに変更できます。表示位置用のレーンは保存しますが、入力は6色すべて有効です。

## 推し変：押したまま隣へ移る

専用音域の **62・64・65・67・69・71** を使います。**前の音符のノートオフと、次の音符のノートオンを同じtick**にしてください。必ず隣の色へ移動し、2音以上つなぎます。重ねる・同じ色へ続ける・色を飛び越す指定はエラーです。

例：62を2拍 → 64を2拍 → 65を2拍と隙間なく配置すると、ピンクで押し始め、2拍後に黄緑、4拍後に白へ移り、6拍後の最後の終端で離す推し変1本です。専用音域では1.5拍未満の区間も推し変の一部です。各区間は実時間で30ms以上、最大129音まで。**別の推し変に分けるときは休符を入れてください**。全トラックを合わせた推し変音域の音符が対象のため、同時に2本の推し変を記述する形式には対応していません。

- スマホ：縦の帯では同じ色を保持し、横向きの矢印が判定線に来たら、指を画面につけたまま隣へ持ち替えます。ボタン間の隙間も近いレーンの入力として扱います。
- PC：矢印の時刻に次のキーを押す、または次のキーを先に押して矢印の時刻に前のキーを離す、どちらでも持ち替えできます。両方を押し続けるだけでは移動の判定になりません。
- ハートの先頭・各矢印での持ち替え・二重線の終端でのリリースをそれぞれ±160ms以内に合わせます。すべてGOOD以上で、最も悪い判定を1本分として採点します。途中で離す・節目を通過し損ねる・終端を離し損ねるとMISSで0点です。移動の節目はコンボ・得点に重複加算しません。
- エディターの「種類」で推し変を選ぶと隣への移動点を1個作ります。「移動先」に `動画上の秒数:レーン番号` をカンマ区切りで指定して細部を調整できます。レーン番号は左から1〜6です。全体の時刻移動・終端変更・範囲コピーにも対応します。クオンタイズで節目が重なる場合は編集を適用せずエラーを表示します。

## テンポ・互換性・サンプル

SMF形式0/1、PPQ、テンポトラックを読み込みます。BPM40〜300、最大5000入力音符、動画時刻0〜7200秒です。拍子は変換を左右しません。未割り当て音、MIDIの欠損、同レーンに重なる入力はエラーにします。推し変は移動先レーンの占有区間も確認します。

既存の38〜47番によるMIDIと、`tap` / `hold` のJSONはそのまま使えます。公式収録譜面SMG002は変更していません。新ギミックは専用音域を指定した場合だけ生成します。

選曲画面の「遊び方」に6種類の練習があります。サンプルMIDIは [oshi-gimmicks.mid](../charts/source/oshi-gimmicks.mid)。120 BPM、1チャンネルで、通常の単推し・同時推し・長推し、箱推し、DD、推し変の順に並びます。音符配置例として利用してください。

CLIで変換する場合も同じ処理を使います（Node.js 24.12以降）。

```sh
node scripts/midi-to-chart.mjs charts/source/oshi-gimmicks.mid charts/source/game-SMG002.config.json /tmp/oshi-gimmicks.json
```

ブラウザで読み込んだだけでは一般公開されません。管理者の「公開」操作を経て配信します。ローカル管理者モードの場合はJSONを書き出してリポジトリの譜面を更新します。

表示は「縦の保持区間＋同じ時刻の横矢印」です。MIDIの移動時刻・判定・描画が対応し、押した時刻で将来の帯の形が変わることはありません。従来の推し変MIDIとJSONはそのまま使えます。
