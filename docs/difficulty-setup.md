# 曲ごとの難易度を追加する

選曲画面で「かんたん・ふつう・むずかしい」を選べます。既存のSUPER MOMMY GIRLS（SMG005）とビスケットケース（BSC002）、既存のオンライン公開譜面・下書きはすべて「ふつう」として引き継ぎます。現在は両曲の「かんたん」「むずかしい」も収録しています。[各譜面の構成とノーツ数](charts/difficulty-variants.md)を参照してください。今後の曲で未作成の難易度は「準備中」で、ほかの難易度の譜面を代わりに再生しません。

## 難易度別の保存・公開を初めて設定する場合

1. Firebaseコンソールで、今までと同じプロジェクトを開きます。
2. Firestore Database → ルールを開きます。
3. この更新の `firestore.rules` 全文をコピーしてルール欄へ貼り付け、「公開」を押します。既存のルールは必要に応じて先に控えておきます。
4. その後、GitHub Actionsの最新 `rhythm-site` をFTPで配置します。[公開手順](sakura-deployment.md)と同じです。

このルール追加は「かんたん」「むずかしい」を別々に保存するために必要です。「ふつう」の保存先・データ・版数は変更せず、データ移行やMySQLの準備は不要です。ルール未更新では新しい難易度の保存が拒否されますが、既存の譜面を新難易度で上書きすることはありません。

## 難易度別の譜面を作成・公開する

1. 管理者ログイン後、「曲」と「難易度」を選びます。
2. 下書きがあればそれを読み込みます。下書きがない場合は対応する収録譜面、収録もなければ空の譜面から始まります。「収録譜面を読み込む」やMIDI／JSON読込、打ち込みで編集できます。
3. 「下書きを保存」で選択中の曲・難易度へ保存します。
4. 「保存してゲームで試す」で、その難易度の非公開下書きを確認できます。
5. 「公開する」の確認に表示される曲名・難易度・ノーツ数を確認して公開します。選曲画面を開き直すと、その難易度で遊べます。

難易度を切り替えても他の難易度のノーツは変更されません。未保存の変更がある場合は切り替える前に確認します。難易度ごとの譜面は個別に作成し、プレイ中の自動間引きは行いません。収録済みの派生譜面も、独立したJSONとして編集できます。

ゲーム画面とリザルトにも難易度を表示します。古いURL（難易度指定なし）は「ふつう」で開きます。未公開や不明な難易度の直接リンクからは選曲へ戻り、仮譜面では遊べません。入力補正・ノーツ音量などの端末設定は難易度間でも共通です。

## 保存先（実装用）

- ふつう：既存の `draftCharts/{song}` / `publishedCharts/{song}`、schemaVersion 1。
- かんたん・むずかしい：各コレクションの `{song}/difficulties/{easy|hard}`、schemaVersion 2。難易度、曲、保存版、保存済み下書きとの一致をサーバールールで検査します。
- ローカル管理者用の下書き・試遊も難易度ごとに分離します。ふつうは従来のキーを維持します。

管理者の保存・公開と一般プレーヤーの閲覧の権限は従来どおりです。一般プレーヤーは公開済み譜面だけを読み取り、下書きの参照・保存・公開はできません。

難易度別のFirestoreルールを設定済みなら、今回の4譜面追加に伴うSQL・Firebase設定の変更は不要です。FTPのサイト一式更新だけで収録版を利用できます。
