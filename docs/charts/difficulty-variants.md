現在、両曲の「かんたん」「むずかしい」は非公開で、一般向けには「準備中」と表示します。ふつうは引き続きプレイできます。既存の譜面JSON・制作ツール・管理者の編集／試遊は保持します。再公開する際は、自作譜面を用意したうえで `src/songs.ts` の各曲の `publicDifficulties` に対象難易度を追加し、サイト一式をFTP更新してください。Firebaseに既存の公開データがあっても、この設定が非公開ならゲーム・ランキングは利用できません。DBやFirebaseのデータ削除は不要です。

## かんたん

元の打点から主に2拍間隔で選び、フレーズ末などには1拍間隔のアクセントを残しています。元のノーツの到達時刻・色は維持します。同時オシは左右1本ずつの少数の組に絞ります。

残す箱オシはDDに、オシ変はレーン移動のない長オシへ整理します。長オシは原則2拍までに短くし、曲末の長オシだけ元の終点を維持します。保持中の親指と同じ側に別の操作を要求しないよう選別しています。

## むずかしい

元のノーツ・長オシ・箱オシ・DD・オシ変をすべて維持したうえで、打点間を拍の座標で分割した交互打ちと、強い拍の左右同時オシを追加します。一部は16分の連なりになります。4小節ごとに加筆しない区間を設け、元譜面の長い空白には追加しません。

追加分には以下の制約を設けています。

- 長オシ・オシ変の始点180ms前〜終点200ms後には加筆しない。
- 箱オシの前後600ms、DDの前後220msには加筆しない。
- 同じ側の親指を続けて使う操作は115ms以上、同じレーンは180ms以上空ける。
- 同時オシは最大2本。追加時は反対側の親指のレーンを選ぶ。

## 制作・検証

初稿は元譜面の打点とテンポマップからオフラインで作成しています。実音を聞きながらの細かな打点の調整や、スマホ実機での難しさの最終確認は行っていません。上のJSONは管理者が個別に調整できる形で保存しています。

`npm run charts:derive` で初稿を再生成できます。このコマンドは4つの派生JSONを上書きするため、個別に調整した後はそのまま再実行しないでください。ゲームのビルド・起動では再生成しません。

検証では、元のふつうのSHA-256不変、派生JSONの再現性、追加分の親指間隔と長オシとの重なり、全6譜面を最後までPERFECTで取り切れること、PHP側の採点一致を確認しています。自動操作での通過確認は、実機の押しやすさや楽曲との聞き合わせの代わりにはなりません。

元データのSHA-256：

- SMG005：`907b0758caedaf6bddcd0109f5c9a7fd5cde0addfb18c146592f1d5916fa76e6`
- BSC002：`dbfbc349b6a51e973911544b73ada967415982bfdd0628252afa46742a3f3cec`

オシ変の終点と同時刻・同レーンの単オシは終端に統合します。このためSMGのふつうは508、むずかしいは891ノーツです。元のJSON・MIDIと派生JSONの配置は保持し、制作ツールは元のMIDI打点を使って既存の派生譜面を再現します。
