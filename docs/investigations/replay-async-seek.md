# リプレイ時にノーツが出ない問題

## 原因と再現

「もういちど遊ぶ」は譜面をリセットしてから YouTube に先頭へのシークと再生を要求する。iframe の時刻・再生状態の更新は非同期のため、要求直後には前の曲の終端時刻や `ENDED` が残る。

従来は `readTime()` が巻き戻し待ちで `playing: false` を返しても、描画ループの動画終了処理が新しい譜面をすべて MISS にしていた。時刻だけ先にゼロになった場合も、古い `ENDED` のまま待機を解除していた。また、5秒のタイムアウト時に古い終端時刻へ譜面をシークし、全ノーツをスキップする経路があった。

公開ビルドのテストで、シークを250ms、再生開始を500ms遅らせると修正前に再現した。従来の同期的な動画モックでは再現しなかった。

## 修正

- 先頭付近の動画時刻と再生中の状態の両方を確認するまで、譜面の進行・終了処理・リザルト表示を止める。
- 待機中は巻き戻しの案内を表示する。
- タイムアウトしてもノーツは未判定のまま残す。再試行を案内し、遅れて巻き戻しが完了した場合にも再開できる。

## 検証範囲

`tests/public/replay-async.spec.ts` はデスクトップとタッチ端末設定で、非同期の巻き戻し後に2回続けてリプレイし、最初のノーツを加点できること、全510ノーツがスキップされず集計されることを確認する。タイムアウト後に再試行し、最初のノーツを加点できることも確認する。

YouTube API のモックを使った回帰テストであり、実際の Android / iPhone と YouTube の組み合わせでの確認は別途必要。
