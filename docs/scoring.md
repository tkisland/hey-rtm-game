# 採点仕様（ルール6）

合計点 = 基本スコア + コンボボーナス + 特殊操作ボーナス。基本スコアは最大1,000,000点、合計点は100万点を超えます。プレイ中・リザルト・X共有・ランキングは同じ合計点です。

## 基本スコア

判定の評価点はPERFECT 1,000、GREAT 750、GOOD 500、MISS 0。譜面全体のプレイ対象ノーツ数をNとして、`floor(獲得評価点の合計 × 1000 / N)` です。ノーツごとの端数を先に捨てず、累積値から計算するため全PERFECTで必ず100万点になります。空の譜面は0点です。

単オシ・長オシ・オシ変・DD・箱オシはそれぞれ1ノーツ分です。箱オシの6個のMIDIマーカーは1個として数えます。オシ変の終点と同時刻・同レーンの通常単オシは終端の重複としてまとめ、追加の押し直し・別判定を要求しません。別レーン・時刻の異なる単オシ・DDなどは独立したノーツとして扱います。同時オシは構成するノーツ数だけ数えます。長さや移動回数は基本配点に影響しません。

同時オシは全ノーツの最終判定が成功してから加点し、1個でもMISS・スキップなら、その組の基本スコア・コンボボーナス・特殊操作ボーナスはすべて0です。成功した側の判定件数・コンボは従来どおり記録します。

長オシは始点と終点、オシ変は始点・全移動点・終点の最も悪い判定を最終判定にします。箱オシは左右の開始の悪い方です。判定窓・操作方法は変更しません。

ルール2からコンボ・特殊操作の配点をともに1.5倍へ引き上げ、ルール4でGOODを50%へ変更しています。ルール5ではGREATを75%へ変更しています。基本スコアの満点・判定条件・確定時期は同じです。

## コンボボーナス

PERFECT・GREAT・GOODでコンボが増え、MISSで0になります。長オシ・オシ変は終了時、箱オシは完了時に増えます。各ノーツの**最終判定が確定した直後のコンボ数**を使います。同時オシの加点待ち中も、そのノーツの確定時の段階を保持します。

| 確定後のコンボ | そのノーツの基本配点への追加率 |
| --- | --- |
| 1〜9 | 0% |
| 10〜19 | 1.5% |
| 20〜29 | 3% |
| … | … |
| 90〜99 | 13.5% |
| 100以上 | 15%（上限） |

GREAT・GOODは基本配点と同じ75%・50%で重み付けします。累積の評価点×段階（0〜10）の合計から `floor(合計 × 15 / N)` を計算します。既に獲得したボーナスはMISSで減りません。コンボボーナス全体は15万点以下で、満点は譜面のノーツ数・成功順で異なります。

## 特殊操作ボーナス

| 操作 | PERFECT成功時の追加点 |
| --- | --- |
| 長オシ | 継続した四分音符1拍につき150点 |
| オシ変 | 継続拍数×150点 ＋ 移動ポイント1個につき450点 |
| 箱オシ | 両手のスワイプ完了で1,500点（全体で1回） |
| DD | 1回受け止めると450点（全体で1回） |

継続拍数は譜面の始点〜終点をテンポマップで拍に変換した長さです。途中のBPM変更も反映し、小数拍は切り捨てます（1.5拍なら1拍分）。オシ変の継続分と移動分は合算します。GREATは75%、GOODは50%とし、ノーツごとに整数へ切り捨てます。

ボーナスは途中では仮加算せず、最後まで成功した時点で確定します。長オシの途中離し、移動点の失敗、終点MISSでは、そのノーツのボーナスも0です。実時間・描画フレーム数・指の移動イベント数・連打回数では増えません。

現行収録譜面を全PERFECTでプレイした検証値：

| 譜面 | 合計点 |
| --- | ---: |
| SUPER MOMMY GIRLS / SMG005 | 1,166,755 |
| ビスケットケース / BSC002 | 1,158,143 |

## リザルト・ランキング

リザルトは合計（TOTAL）と、基本スコア／1,000,000・コンボボーナス・特殊操作ボーナス・最大コンボ・判定件数を表示します。「基本スコア得点率」はボーナスを含めず、`獲得評価点 / (判定済みノーツ数 × 1000)` です。シークした場合はスキップ数も表示し、基本スコアの分母を残りノーツ数へ縮めません。

採点ルールの版を5から6へ更新します。ランキングは同じ曲・難易度・譜面でも別区分となり、旧ルール1〜5の記録はDBに保持し、公開画面では表示しません。DB構造の変更は不要です。ブラウザの最終判定順を元にPHPでも全内訳を再計算し、合計点・最大コンボが一致した場合だけ登録します。

特殊操作の配点・コンボ段階・端数処理を含めて今後変更する場合も、ブラウザとPHPを同時に更新し、採点ルールの版を上げます。


## 得点率によるメッセージ

基本スコアを100万点で割った得点率を使用し、ボーナスは含めません。スキップした分を除いて満点へ換算し直すこともしません。

| 基本得点率 | メッセージ |
| --- | --- |
| 100% | 伝説のLIVE！ |
| 95%以上 | 最高なLIVE！ |
| 85%以上 | 大盛り上がりのLIVE！ |
| 70%以上 | いい感じのLIVE！ |
| 50%以上 | レスが届いたLIVE！ |
| 50%未満 | また一緒にLIVEしよう！ |

ゲーム終了時・リザルト・X本文・共有ページ・OGP画像で同じ文言を使います。リザルトは「ランキング登録」を表示し、上位20件と詳しい採点説明は初期状態では閉じます。通常のスマホ縦画面で登録フォームをスクロールなしで操作できるよう、余白と文字サイズを調整しています。小さな横画面・キーボード表示時・文字拡大時はスクロールして全項目へアクセスできます。

ルール6ではオシ変の終端と重なる単オシをプレイ対象から除きます。SMG005の114.136秒・128.511秒付近で、正常なGREAT/GOODリリース後に重複ノーツがMISSになる問題を修正します。元のMIDI・JSONは保持し、ゲーム・再生確認・ノーツ数表示・PHP採点が同じプレイ対象を使います。通常の長オシと単オシの組み合わせは従来どおりです。
