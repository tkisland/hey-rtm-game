# 見本プレイ

選曲カードの「見本プレイ」から、その曲・難易度の自動操作を見られます。動画は通常と同じく「ゲームスタート」で再生します。ノーツ音の音量とノーツ全体の位置、表示時間は普段の設定を使います。タップ入力の補正は自動操作には適用しません。

単オシ・同時オシ・DDは押すタイミング、長オシは保持と終点のリリース、オシ変は各移動先、箱オシは中央から外への操作を、ノーツ音・ボタンの点灯・判定演出で表示します。キーやタッチ入力で判定を変えることはできません。動画の一時停止・再開に合わせて止まり、「↻」や「もういちど見る」で先頭から見直せます。動画をシークした場合、飛ばしたノーツは通常と同じくスキップします。

画面には「見本プレイ · AUTO」、結果には参考スコアであることを表示します。ランキングのプレイ情報を発行せず、結果の登録とX共有も表示しません。結果の「自分で遊ぶ」から同じ曲・難易度の通常プレイへ移れます。非公開の難易度は見本プレイでも利用できません。

自動操作は動画から得たゲーム時刻に沿って、フレーム間に通過した打点を順番に処理します。別のタイマーで動画を追い越す方式ではありません。通常プレイでは自動操作のスケジュールを生成しません。
