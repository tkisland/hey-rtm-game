# 曲名・点数入りのリザルト共有

リザルトの「Xで共有」は、曲名・難易度・合計点・最大コンボ・得点率別メッセージと、専用の `share.php` URLをXの投稿画面へ渡します。実際の投稿は利用者が確認して行います。投稿文は `#HeyRhythm`、得点率別メッセージ、曲名・難易度、スコア、最大コンボ、共有URLの順に改行します。曲のアーティスト名のハッシュタグは付けません。シークした場合の注記はメッセージ行に含めます。

共有ページはPHPでHTMLとOGPメタタグを返すため、JavaScriptを実行しないクローラーでも取得できます。`share-image.php` は背景に日本語の曲名・難易度・メッセージ・合計点・最大コンボを描いた1200×630のPNGを返します。シークしたプレイではスキップ数を表示します。

## FTP更新

マージ後の `rhythm-site` 全体を通常どおり `https://hey.jpn.org/rhythm/` に置きます。特に以下のファイル・フォルダーを含めて更新してください。

- `share.php`、`share-image.php`、`share-common.php`
- `share/`（背景PNG・Dela Gothic Oneフォント・OFLライセンス）
- `api/core.php`、`api/catalog.json` とHTML・JS・CSS

追加のAPIキー、Xログイン連携、SQL変更は不要です。さくらのPHPでGDとFreeTypeが有効である必要があります。ゲームの通常プレイ中は画像の生成・背景・フォントの追加取得を行いません。

設置後、次のURLで共有ページと画像を確認できます（サンプルの表示結果です。ランキングには登録しません）。

```
https://hey.jpn.org/rhythm/share.php?song=biscuit-case&difficulty=normal&v=7&art=3&score=1160000&base=960000&combo=328&skipped=0
```

同じクエリで `share.php` を `share-image.php` に置き換えるとPNG自体を確認できます。これが表示されればGD・日本語フォントを利用できています。ページの「この曲で遊ぶ」から対応する曲・難易度へ進めます。新規の共有URLには画像版の `art=3` を付け、以前の画像キャッシュと区別します。画像版を持たない以前の共有リンクも開けます。共有ページは検索用に大量インデックスされないようnoindexにしています。

Xのカードの表示・キャッシュ更新はX側の取得状況にも依存します。実際の投稿で画像が表示されるかは設置後に確認してください。結果ごとに共有URLが変わるため、従来のゲームページの画像キャッシュとは区別されます。

## 表示データ・ランキングとの関係

共有URLは名前などの個人情報を含まず、曲ID・難易度・数値・採点版だけを含みます。曲名はサーバーのカタログを使い、自由入力の文字列・画像URL・ファイルパスは受け付けません。数値の範囲を検証し、HTMLの出力をエスケープします。サーバーから外部画像を取得する処理や、画像を蓄積するDB／ファイル書込みはありません。

共有用の表示データはURLから読み取ります。ランキングの検証・登録とは独立しており、共有URLを編集してもランキングには影響しません。ランキング登録前・ランキングが準備中でも共有できます。

PNG背景は画像生成で制作しています。文字の描画にはDela Gothic Oneを使用し、SIL Open Font Licenseを `share/OFL.txt` に同梱しています。

公開ページと共有画像から開発段階の版表記を除いています。共通OGPは `ogp-v2.png` へ更新し、以前の画像URL `ogp-test-v1.png` にも同じ新画像を置くため、FTP更新で旧画像も上書きできます。Xに保存済みのカードはX側のキャッシュ更新に依存します。

採点ルール7の共有URLに対応し、以前のルール4〜6で共有した結果のリンクも引き続き表示します。

画像から基本スコアを除き、合計点と最大コンボを表示します。新規共有リンクは画像版3を使用します。以前の画像版2のリンクも引き続き開けますが、投稿済みのカード画像の更新はX側のキャッシュに依存します。
